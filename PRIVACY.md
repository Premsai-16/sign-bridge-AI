# Privacy & Data Governance

## Principles
SignBridge AI prioritizes privacy by design. No raw camera video or audio is stored by default.

## Data Collection
- **Landmark samples**: Personal sign examples are collected only after explicit consent and stored in browser local storage
- **Transcripts**: Session history is stored in browser local storage when the user saves it
- **Biometric data**: Never committed to repository

## User Control
- Export all personal data anytime
- Delete samples and models reliably
- Clear consent records with timestamps
- Model retraining after corrections

## Technical Safeguards
- Inference on-device where practical
- No API secrets in browser bundles
- Structured errors without sensitive payload logging
- CORS configured for production
